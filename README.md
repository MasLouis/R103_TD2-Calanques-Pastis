# Le pastis

Le pastis est une boisson anisée appréciée dans le sud de la France.

## Comment le déguster

- Versez une dose de pastis dans un verre.
- Ajoutez de l’eau fraîche.
- Ajoutez des glaçons selon votre goût.

> À consommer avec modération.
